# Trappy Flump — website

The landing page for the Android app: the game itself, playable in the
browser, plus the breaking-news rundown, an about section, the privacy policy
Google Play requires, and a download call to action.

Plain static files, no build step. Served by GitHub Pages from the root of
this repository. The game itself (terminal, Godot/Android, audio sources)
lives in the private `trappy-flump` repository; this site is a port of it.

```
index.html     landing page: hero with the live game, events, about, CTA
privacy.html   privacy policy (link this URL in Play Console and AdMob)
style.css      one stylesheet for both pages
game.js        the game, a port of mobile/scripts/game.gd (trappy-flump repo) to canvas
audio.js       Web Audio layer: listens to game events, owns the mute toggles
audio/         generated sounds (do not edit; built by assets/audio/ in the trappy-flump repo)
favicon.svg    the head sprite, generated from the same grid as the game
title.svg      the header title, rendered from the game's 3x5 font by tools/title.js
app-ads.txt    AdMob authorised-seller line; must be served at the domain root
test/soak.js   headless soak test of game.js (see below)
.nojekyll      tells GitHub Pages to serve the files verbatim
```

## Run locally

```sh
python3 -m http.server 8000
# then open http://localhost:8000/
```

## Deploy

GitHub Pages serves this repository as is: Settings > Pages > Build and
deployment > Source "Deploy from a branch", branch `master`, folder `/ (root)`.
Every push to `master` republishes the site. The repository root has to be
the root of the domain you enter as the developer website in Play Console,
so that `app-ads.txt` resolves at `https://<domain>/app-ads.txt`; AdMob only
checks the root. For a custom domain, add a `CNAME` file with the bare
domain name and point the DNS at GitHub Pages.

## The browser game

`game.js` is a faithful port of the Godot scene: same sprites, palette, 3x5
and 5x7 fonts, physics in head units, event table, menus and drawing order.
It renders into a 128x228 canvas that the page scales up by a whole number
with `image-rendering: pixelated`. The menu has the same sound, music and
achievements buttons and best-score panel as the app; play has the home
button; game over has the MENU button and the head that tumbles, lands and
bawls in the corner. Ads and Play Games do not exist on the web, so there is
no "AD CONTINUE" button and no Privacy button; best score and unlocked
achievements live in `localStorage`.

Taps go through `game.tap(x, y)` in canvas pixels (keys tap at -1,-1, which
misses every button). The game never touches audio: its menu buttons emit
`sound` / `music`, `audio.js` owns the preference and mirrors it back with
`game.setAudio()`, and the HTML toggles under the frame follow through
`audio.onchange`.

Keep `game.js` in step with `mobile/scripts/game.gd` in the `trappy-flump`
repository when gameplay changes. The event table and the achievements list
are duplicated at the top of `game.js` (from `events.gd` and
`play_services.gd`); the copy on `index.html` describes the same numbers in
words.

## Soak test

```sh
node test/soak.js 20         # simulated minutes, default 5
```

Runs the real update and draw code on a stub canvas with a tapping autopilot,
pokes the menu buttons (achievements list, sound switch) and the home / MENU
buttons between runs, and prints deaths, best score, how often each event
fired and which achievements unlocked. It exits non-zero if an event never
fires, the autopilot cannot reach a score of 5, a screen or button is never
hit, or achievements do not persist.

## Before going live

- The Play Store links point at
  `https://play.google.com/store/apps/details?id=com.eiilo.games.trappyflump`,
  which only resolves once the app is published. Until then they 404.
- Paste `privacy.html`'s public URL into Play Console (Store listing and
  Data safety) and into the AdMob app settings.

## Audio

Every sound is generated by `assets/audio/gen.py` in the `trappy-flump`
repository and encoded into `audio/` here by its `assets/audio/build.sh`
(run it with this repository checked out next to the game, or point
`WEB_AUDIO` at this `audio/` directory); nothing here is hand-edited. Browsers
block audio until a user gesture, so the first click on the frame both
focuses the game and unlocks sound. Sound defaults on, music defaults off;
both toggles persist in `localStorage`. Music ships as OGG Vorbis, which
Safari cannot decode, so Safari plays effects only.
